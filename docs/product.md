# ScreenSway product brief

## Promise

Beautiful screen recordings that guide the viewer automatically, without watermarks or cloud uploads.

## Product principles

1. Local-only by default. Recording, editing, and rendering stay on the device.
2. Free full feature set at launch. No export limits and no watermark.
3. Calm automation. Automatic zooms should feel intentional and remain editable.
4. Native capture quality. Platform-specific capture backends feed one shared project model.
5. No account required.

## First vertical slice

1. Select a display or window.
2. Record a clean screen video for at least 30 seconds.
3. Store timestamped pointer movement and click events separately.
4. Open the recording in a preview.
5. Generate editable zoom segments from click activity.

The first macOS vertical slice now records the main display, writes local project metadata, and previews generated zooms. Source selection, early stopping, audio, webcam, captions, cloud sharing, and advanced audio processing remain outside this slice.
